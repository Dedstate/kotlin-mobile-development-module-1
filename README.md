# Часть III – Практическое задание

## Задание 1

1. Напишите compose-функцию `Hello(name: String?)`, куда в качестве параметра можно было бы
   передавать имя для приветственной надписи. Если в качестве параметра передано значение `null`,
   должна выводиться надпись «Имя не задано».
2. Вызовите функцию в активити.
3. Отдельно скомпилируйте проект, передав в функцию конкретное имя, и отдельно — передав значение
   `null`.

---

## Задание 2

Создайте для функции `HelloPreview` из предыдущего урока три макета предпросмотра с показом
системного UI:

1. `portrait` — с портретной ориентацией экрана.
2. `landscape` — с альбомной ориентацией экрана.
3. `round` — с круглым дисплеем размером `200dp` x `200dp`, а также жёлтым задним фоном (`dp` —
   единица измерения размера экрана, про неё будет отдельный урок).

---

## Задание 3

Добавьте в ресурсы строку:
> «Jetpack Compose — это современный набор инструментов для создания пользовательского интерфейса (
> UI) на Android, разработанный Google».

Разместите в режиме предпросмотра текст с этой строкой в нескольких вариантах:

1. Зелёный цвет шрифта, размер шрифта — `16.sp`, стиль шрифта — курсив, выравнивание — по центру.
2. Для текста отводится одна строка, в завершении которой — многоточие (как признак того, что текст
   не умещается).
3. Перед первой строкой — отступ `48.sp`, размер шрифта — `24.sp`, чёрный цвет шрифта, зелёный цвет
   фона, текст подчёркнут.

---

## Задание 4

Попробуйте самостоятельно определить значения параметров и вывести на экран кнопку такого вида:

1. Для растягивания кнопки по ширине экрана задайте параметр `modifier`.
2. Для установки формы прямоугольника со скруглёнными углами используйте параметр `shape` со
   значением `RoundedCornerShape(16.dp)`.
3. Для границы кнопки задайте значение `BorderStroke(2.dp, Color.Gray)`.
4. Установите тень глубиной `4.dp`.
5. Для фона кнопки выберите светло-серый цвет (`Color.LightGray`), а для цвета текста — чёрный (
   `Color.Black`).

---

## Задание 5

Выполнить задание можно в отдельном проекте или в новом файле в уже существующем проекте.

Итак, задача такая:

1. Разместите во всю ширину экрана серый контейнер высотой `100.dp`.
2. Расположите посередине компонент с инициалами с вертикальными отступами `16.dp`.
3. Круг должен занимать всю доступную высоту.
